# gobrew v0.2.0

新增 curl 安装入口、`gob` 符号链接，以及 gobrew 自身的更新和卸载命令。`gobrew` 保持主命令，Formula 安装位置和已有软件数据不变。

## 安装与启动

支持 Apple Silicon、macOS 15 或更新版本；运行发布程序不需要安装 Go。

```sh
curl -fsSL https://github.com/shqingda/gobrew/releases/latest/download/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
gob --help
```

命令默认安装到 `~/.local/bin`，其中 `gob` 是指向 `gobrew` 的符号链接。安装器以普通用户运行，不自动修改 shell 配置；可将 `export PATH` 加入 `~/.zshrc` 以供后续终端使用。已有同名外部文件不会被覆盖。

指定本版本和其他命令目录：

```sh
curl -fsSL https://github.com/shqingda/gobrew/releases/download/v0.2.0/install.sh \
  | GOBREW_VERSION=v0.2.0 GOBREW_BIN_DIR="$HOME/bin" sh
```

使用自定义目录时，请将它加入 `PATH`。也可以先下载、查看安装脚本后再运行。安装器核对官方 Release 中的 SHA-256 校验文件；该文件与压缩包来自同一 GitHub 信任域，不构成独立签名。

首次使用 Formula 存储时，再单独初始化：

```sh
sudo "$HOME/.local/bin/gobrew" init
gobrew init
eval "$(gobrew shellenv)"
gob install hello jq
```

若 `/opt/gobrew` 已由当前用户拥有，省略 `sudo` 步骤。自定义命令目录需使用其实际可执行文件路径。日常包操作不使用 root。

## 自身更新与卸载

```sh
gob self update
gob self uninstall
```

- `self update` 下载并校验最新稳定发布，原子切换程序，不自动降级。
- `self uninstall` 移除托管的 CLI 程序和两个命令链接，保留已安装 Formula、配置、数据和缓存。
- 少量归属记录与锁文件留在命令目录的 `.gobrew` 中，用于安全重试和重新安装；用户修改过的文件不会被静默删除。
- 手工解压的本版程序可运行 `./gobrew self install` 加入托管安装。未托管的程序不支持自身更新或卸载。

`gobrew update` 仍用于刷新 Formula 目录，`gobrew upgrade` 用于升级软件包，`gobrew uninstall NAME` 用于卸载指定软件包。已有 v0.1.0 用户可通过本版 curl 安装器建立托管安装；它不会接管旧的手工放置程序，遇到路径冲突时需先自行处理。

## 发布资源与检查

发布资源包含 ARM64 压缩包、安装脚本、`checksums.txt` 和本次二进制的 `benchmark.json`。将四个文件下载到同一目录后，可运行 `shasum -a 256 -c checksums.txt` 验证。

发布流程要求通过代码检查、CLI 引导安装与自身生命周期测试、macOS 实机 Formula 烟测及五轮性能门槛。具体运行结果以对应 GitHub Actions 和随附基准数据为准。
