# gobrew v0.4.0

本版新增指定版本安装，完善日常安装、更新和清理行为，并修复依赖保护及卸载体验。支持 Apple Silicon、macOS 15 或更新版本。

## 安装与升级

已安装正式版的用户执行：

```sh
gob self update
```

首次安装或正在使用 `dev` 测试版的用户执行：

```sh
curl -fsSL https://github.com/shqingda/gobrew/releases/latest/download/install.sh | sh
```

更新 CLI 不会重新安装已有 Formula；安装前缀仍为 `/opt/gobrew`。

## 新增与调整

- 新增 `gob version-install uv 0.13.5` 和 `gob version-install uv@0.13.5`，安装指定版本的官方 bottle 并自动 pin。历史版本通过 GHCR 与配方 bottle 记录双源核对摘要；不执行 Ruby、不构建源码。`install uv@0.13.5` 不作为指定版本语法。
- `install` 升级本地目录中已知过时、未 pin 的请求项；健康且无需替换时直接返回。显式安装原本自动带入的依赖会将其标为 `requested`，避免以后被自动清理。
- `install`、`upgrade`、`outdated` 在目录过期时尝试自动更新 CLI 和目录；可通过 `GOBREW_NO_AUTO_UPDATE=1` 关闭。`reinstall`、`version-install` 和 dry-run 不触发自动更新。
- 安装成功后清理相关旧版本，并按周期执行全量清理；保留仍被引用、pin 或恢复所需的材料。
- **卸载现在会自动移除无用依赖**，与 `autoremove` 使用同一规则。主动安装、pin 及仍被这些包需要的依赖会保留；仍被依赖的包不能直接卸载。卸载结果显示 `Uninstalled`，自动清理另有数量提示。
- 完善搜索及常用命令别名；保留 gobrew 自己的 JSON 接口，不承诺完整兼容 Homebrew 的全部参数或功能。

## 修复

- dry-run 不再触发自动更新或替换 CLI。
- 降级时检查保留消费者的最低依赖版本，避免仅凭 ABI 提示放过不兼容版本。
- 指定历史版本时正确加载历史配方独有的依赖闭包。
- 离线 no-op 不再无依据地提示“已是最新版本”。

## 验证与发布资源

发布流程要求通过代码检查、bootstrap、自身生命周期测试、macOS 15/26 实瓶测试及五轮 Homebrew 性能门槛。发布的可执行文件来自通过性能验证的同一构建；具体结果见本次 Actions 和随附的 `benchmark.json`。

发布资源包含 ARM64 压缩包、安装脚本、`checksums.txt` 和 `benchmark.json`。下载到同一目录后执行 `shasum -a 256 -c checksums.txt` 验证。摘要文件与压缩包来自同一 GitHub 信任域，不构成独立签名。

此前 nanobrew 对比中，hello/jq 的等价场景已测；uv 因依赖集合不同不作速度比较。结果见仓库 `docs/nanobrew-comparison.md`，不代表所有软件的性能结论。
