# gobrew v0.1.0

首个公开版本。使用 Go 实现的 macOS Formula 包管理器，使用 Homebrew 官方 core 元数据和 bottles，默认安装在独立的 `/opt/gobrew`。

## 运行要求

- Apple Silicon，macOS 15 或更新版本。
- 下载 `gobrew_0.1.0_darwin_arm64.tar.gz`；运行预编译程序不需要安装 Go。
- 部分 bottle 的重定位和初始化需要 macOS 系统工具。首次创建 `/opt/gobrew` 需要管理员权限，日常操作使用普通用户。

## 功能

- 查询、依赖分析、安装、重装、升级、卸载、pin、链接管理、缓存清理及故障修复。
- 官方签名目录和 bottle SHA-256 验证、安全解压、独立 prefix 重定位及签名处理。
- 并发下载与准备、不可变缓存、APFS 克隆；已安装检查使用本地记录。
- 持久化操作日志、文件归属检查、配置保留及显式初始化修复。
- JSON 输出、shell 补全和只读导入 Homebrew 安装清单。
- 独立的中文 Go 1.27.3 入门教程，包含必要代码注释和可执行示例。

## 下载与验证

将压缩包、`checksums.txt` 和 `benchmark.json` 下载到同一目录后执行：

```sh
shasum -a 256 -c checksums.txt
tar -xzf gobrew_0.1.0_darwin_arm64.tar.gz
cd gobrew_0.1.0_darwin_arm64
./gobrew version
sudo ./gobrew init
./gobrew init
eval "$(./gobrew shellenv)"
./gobrew install hello jq
```

若 `/opt/gobrew` 已由当前用户拥有，省略 `sudo` 初始化。可将 `gobrew` 可执行文件放入个人 `PATH` 中的目录。详细命令、恢复语义及迁移方式见随包提供的 README。

## 支持范围与验证

支持官方 core 及版本化 Formula。首版不支持 Cask、第三方 tap、源码构建、services、任意历史版本或 Intel；未知安装步骤和旧 Ruby hook 会明确拒绝。

发布必须通过格式、静态分析、race 测试、教程示例、漏洞扫描、macOS 15/26 ARM64 真实 bottle 烟测，以及五轮冷安装和热重装性能比较。随附 `benchmark.json` 记录本次发布二进制的实测结果；实际速度受机器、网络和安装集合影响。

CLI 当前以 0.x 版本迭代。未来 macOS 客户端将复用 Go 核心，本版不包含 GUI。
