# gobrew v0.6.0

This release brings back `self`, adds more of Homebrew's commands and flags, and fixes defects found in a review of v0.5.0. Read-only commands now work while another gobrew command is installing, and errors and progress are clearer. It supports Apple Silicon on macOS 15 or newer.

## Installing and upgrading

If you have v0.5.0 or another release installed:

```sh
gob update
```

For a first install, or if you are using a `dev` test build:

```sh
curl -fsSL https://github.com/shqingda/gobrew/releases/latest/download/install.sh | sh
```

Upgrading the CLI does not reinstall your existing formulae. The installation prefix is still `/opt/gobrew`.

## `self` is back

v0.5.0 removed `self`. It is back, with the behavior it had before v0.5.0:

- `gob self install [--bin-dir DIR]` installs the CLI.
- `gob self update` updates only the CLI; `gob update` still updates both the CLI and the formula catalog.
- `gob self uninstall` removes the CLI and keeps installed software, configuration, data and caches.

`install.sh` and `uninstall.sh` still work. `self` is the one gobrew command that Homebrew does not have.

## New commands

- `config` prints what a bug report needs: version, paths, the catalog's generation and refresh time, whether the CLI is managed, macOS, and the `GOBREW_*` settings in effect. Tokens are shown only as `set`.
- `leaves` (`-r`, `-p`), `desc` (`-s`, `-n`, `--description`) and `home` (also `homepage`) work as in brew.
- `gob --prefix`, `--cellar` and `--cache` print paths like brew, including `--installed`, `--unbrewed` and `--bottle-tag`.
- `gob help environment` lists every environment variable gobrew reads.

## More of brew's flags

- Global `-v/--verbose` and `-d/--debug`. On its own, `gob -v` still prints the version. With `--verbose`, install commands show per-package and stage times.
- `deps` and `uses`:
  - `--tree`, `--graph`, `--dot` and `--annotate`.
  - `--missing` and the `--include-*` options.
  - `--prune`, `--topological` and `--for-each`.
  - Declared dependency tags.
- `list`: `-l`, `-r`, `-t`, `--multiple` and `list <formula>`.
- `install`:
  - `--as-dependency` and `--only-dependencies`.
  - `--skip-link` and `--skip-post-install`.
  - `--display-times` and `--include-test`.
  - `-f/--force`, which installs a disabled formula with a warning.
  - `-y/--yes` and `--force-bottle`.
- `outdated` and `upgrade`: `--minimum-version` (or `--min-version`).
- `info`: `--analytics`, `--sizes` and `--github`, plus brew's layout for dependencies, deprecation and post-install errors.
- `search`: `--pull-request` and the package-database switches such as `--debian`.
- `link`/`unlink`: `--dry-run`. `link`: `-f`.
- `cleanup`: `--prune-prefix`.
- The cask-only and HEAD-only options of install commands are accepted and ignored. Options that conflict report brew's "mutually exclusive" message.
- Some input that gobrew cannot act on is refused with an explanation instead of "unknown flag": `--cask`, and Homebrew commands gobrew deliberately leaves out, such as `tap`, `services` and `bundle`. A mistyped command gets a "Did you mean" suggestion.

## Fixes

- **Disk use:** old formula-catalog snapshots, about 60 MB each, are now reclaimed after an update and by `cleanup`. Previously one accumulated every time upstream changed.
- **Downloads:** a slow but steady download no longer times out. A download that stalls for a minute is retried, and each retry prints a line.
- **Concurrency:**
  - `list`, `info`, `doctor` and other read-only commands run while another gobrew command is installing. Previously they exited with "busy".
  - A second writer waits up to 10 seconds and then names the cause.
- **fish:** gobrew's startup lines no longer hide the system manual pages when `MANPATH` was unset.
- **PATH hint:** the manual PATH hint now uses the absolute path of `gobrew`, so it works before gobrew is on `PATH`.
- **Cleanup:**
  - Very large `--prune` days, `GOBREW_CLEANUP_*` and `GOBREW_AUTO_UPDATE_SECS` values no longer wrap around. Previously they could empty the cache.
  - Empty staging, backup and trash directories are now removed.
- **Exit codes:**
  - A failure to evict cache entries no longer turns a successful install into an error.
  - A failed `open` is reported as such, not as a failure to write output.
- **Post-install:** the last line of post-install output is no longer lost when it has no newline.
- **Newer macOS:** on a macOS release newer than gobrew knows, catalog normalization falls back to the newest known release, as bottle selection already did.
- **`install.sh`:** a Rosetta terminal is no longer mistaken for an Intel Mac, and each failure explains itself.

## Clearer messages

- Unknown formulae use brew's wording and suggest close names, for example `No available formula with the name "jqq". Did you mean jq?`.
- Formulae that are not installed are reported as `No such keg: ...`.
- `uninstall` names every installed formula that still needs the one being removed.
- Internal prefixes such as `unsupported:` and `conflict:` no longer appear in text output.
  - Interrupting a command explains that gobrew stops only between safe steps.
  - A command that needs repair says which command to run next.
- `==>` titles and `Warning:` and `Error:` labels are colored on a terminal. `NO_COLOR`, `HOMEBREW_NO_COLOR`, `GOBREW_NO_COLOR` and `TERM=dumb` turn color off. `GOBREW_NO_EMOJI` also applies to `info`.
- The first catalog download, `update` and the catalog's verification step show progress.

## `doctor`

- It now also warns about:
  - an unsupported Mac;
  - a missing or week-old catalog;
  - an unwritable cache;
  - a CLI that `self install` does not manage;
  - a damaged gobrew block in your shell startup file.

  These warnings do not change its exit status.
- `doctor --repair` now also recreates links that gobrew installed but that were later deleted. A file someone put in a link's place is left alone and reported.

## Performance

- `info`, `desc`, `home` and `outdated` read only the formulae they name. This takes them from about 60 ms to under 10 ms.
- When the catalog has not changed, `update` reuses the index it already built. This halves its CPU time. The catalog signature is still verified every time.

## JSON output

- Install commands add a `notes` field for PATH and cleanup notes.
- `outdated <formula>` exits with status 1 when a named formula is outdated, as brew does, with or without `--json`; the JSON error code is `outdated`.
- `doctor` findings can have the severity `fixed`, for what `--repair` corrected.
