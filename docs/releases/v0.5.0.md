# gobrew v0.5.0

This release makes gobrew's commands a subset of Homebrew's: the commands it keeps take the same flags and have the same default behavior as in brew. It also removes the four commands Homebrew does not have, and tidies the code and speeds up downloads. It supports Apple Silicon on macOS 15 or newer.

## Installing and upgrading

If you have v0.4.0 or another release installed:

```sh
gob update
```

For a first install, or if you are using a `dev` test build:

```sh
curl -fsSL https://github.com/shqingda/gobrew/releases/latest/download/install.sh | sh
```

Upgrading the CLI does not reinstall your existing formulae. The installation prefix is still `/opt/gobrew`.

## Incompatible changes

- **Removed `self`, `init`, `import-homebrew` and `completion`**, because Homebrew has none of them:
  - Installing the CLI: the curl installer does it for you.
  - Updating the CLI: use `gob update`.
  - Uninstalling the CLI: use the separate `uninstall.sh`, as Homebrew does:

    ```sh
    curl -fsSL https://github.com/shqingda/gobrew/releases/latest/download/uninstall.sh | sh
    ```

  - Initializing `/opt/gobrew`: the first `gob install` does it. When administrator access is needed, sudo runs only a fixed `mkdir` and `chown`, and gobrew itself never runs as root.
  - Migrating from Homebrew: use `brew list --installed-on-request | xargs gob install`.
  - Shell completion: no longer provided.
- **`version-install` no longer pins automatically**, the same as brew. `upgrade` later upgrades the package to the current version. To keep the old version, run `gob pin NAME`.
- **`list` and `outdated` print brew's text format.**
  - `list` prints names only; `--versions` adds the versions.
  - In a terminal, `outdated` shows `name (installed version) < new version`. In a pipe it prints names only.
  - Use `--json` if you need structured output.

## Behavior aligned with brew

- `upgrade` skips pinned packages and prints `Not upgrading N pinned package(s)`. It exits with code 1 only when you name a pinned package explicitly; other packages are upgraded as usual.
- `deps` and `uses` accept several formulae and show what they have in common.
  - `deps` adds `--union`, `-1/--direct` and `--installed`.
  - `uses` adds `--recursive`.
  - An empty result prints nothing.
- `shellenv` takes the shell as an argument, for example `gob shellenv zsh`.
  - Without an argument it uses `$SHELL`.
  - It adds csh/tcsh/pwsh output.
  - Unknown shells get POSIX output.
- `search` without text lists every formula. `outdated` accepts formula names and `-v`.
- Accepts brew's `-n` (dry run), `-y/--no-ask` and `--formula`. gobrew only has formulae and never asks for confirmation, so these change nothing.

## Other improvements

- Bottle downloads try Homebrew's anonymous credential first, removing one GHCR round trip.
- An error now explains a bottle's prefix-length limit, for example: `bin/jq embeds /opt/homebrew/Cellar/jq/1.8.2 in compiled data, so the prefix must be at most 13 bytes`.
- Improved progress, hints and error messages.
- Removed dead code and split the large files.

## Remaining differences from brew

These are listed in `docs/status.md` in the repository. Some are kept on purpose for correctness:

- There is no `uninstall --ignore-dependencies`.
- There is no `link --overwrite`.
- If upgrading a dependency would break a package that depends on it and is pinned, gobrew refuses before switching anything.

## Verification and release assets

The release pipeline requires code checks, the bootstrap and install/uninstall tests, real-bottle tests on macOS 15 and 26, and five rounds of Homebrew performance thresholds. Results are in this run's Actions and the attached `benchmark.json`.

Release assets: the ARM64 archive, `install.sh`, `uninstall.sh`, `checksums.txt` and `benchmark.json`. Download them into one directory and run `shasum -a 256 -c checksums.txt` to verify them. The checksum file comes from the same GitHub trust domain as the archive, so it is not an independent signature.
