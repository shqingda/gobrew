# gobrew v0.7.0 (draft)

This release brings gobrew closer to Homebrew: outdated dependents upgrade the way Homebrew upgrades them, and the install and uninstall output and `shellenv` match Homebrew. Cold installs are faster, and `gobrew` and `gob` now have shell completions. It supports Apple Silicon on macOS 15 or newer.

## Installing and upgrading

If you have v0.6.0 or another release installed:

```sh
gob update
```

For a first install, or if you are using a `dev` test build:

```sh
curl -fsSL https://github.com/shqingda/gobrew/releases/latest/download/install.sh | sh
```

Upgrading the CLI does not reinstall your existing formulae. The installation prefix is still `/opt/gobrew`.

## Outdated dependents are upgraded

When `install`, `upgrade` or `reinstall` changes a formula, gobrew now also upgrades that formula's outdated installed dependents. This works like Homebrew's `upgrade_dependents`:

- The dependents are upgraded in the same operation, under the same lock and journal.
- gobrew prints `==> Upgrading N dependents of upgraded formulae:` and lists each version change. A dry run prints `Would upgrade` instead.
- gobrew does not upgrade pinned dependents. It prints `Warning: Not upgrading N pinned dependents:` and lists them.
- To turn this off, set `GOBREW_NO_INSTALLED_DEPENDENTS_CHECK=1`.

## Output that matches Homebrew

- Each poured keg prints `🍺  <keg>: N files, SIZE`. To leave out the badge, set `HOMEBREW_NO_EMOJI` or `GOBREW_NO_EMOJI`.
- `uninstall` and `autoremove` print `Uninstalling <keg>... (N files, SIZE)`, and `==> Autoremoving N unneeded formulae:` for the dependencies they remove. When there is nothing to remove, `autoremove` prints nothing.
- A retried download prints `Retrying download of jq in 1s... (2 tries left)`. Network errors show the host name only, not the signed URL.
- `--prune=0` and `GOBREW_CLEANUP_MAX_AGE_DAYS=0` now mean "all", as in Homebrew.
- `GOBREW_COLOR` or `HOMEBREW_COLOR` forces color output. `NO_COLOR` still takes precedence.

## Shell completions and `shellenv`

`install.sh`, `gob self install` and `gob self update` write zsh, bash and fish completions for `gobrew` and `gob`. The scripts are generated from the verified executable. gobrew's shell startup block loads them. gobrew still has no `completion` command. Bash completion needs bash-completion, as Homebrew's does.

`gobrew shellenv` now matches `brew shellenv`:

- In zsh, `fpath` starts with the prefix's `share/zsh/site-functions`.
- An existing `MANPATH` is normalized to begin with one colon, so `man` keeps its default directories.
- `INFOPATH` includes the prefix's `share/info`.

## Faster cold installs

Five alternating rounds on an M3 Pro (hello and jq): the median cold install fell from 2041 ms to 1362 ms. Three changes made this:

- OCI metadata is fetched while the bottle downloads.
- Extraction no longer resolves every path one component at a time.
- Relocation skips needless permission changes.

After an install, cleanup no longer scans every keg when there is nothing to clean up. Digest checks, signature checks and durability are unchanged. For the details, see [performance.md](../performance.md).

## Other fixes

- When releasing the lock or evicting the cache fails after a successful install, gobrew prints a warning. The command still succeeds.
- A first install creates the prefix before it downloads anything. Without a terminal, a prefix that needs `sudo` therefore fails at once.
- Progress headlines are never dropped. The download bar follows window resizes, fits narrow terminals and shows the download speed.
- A repair error names the command that fixes it, for example `gobrew postinstall jq`.
- A "busy" error names the state database and says what to do.
- The first Ctrl-C now says at once that gobrew stops after the current step.
- With `--json`, warnings go in the envelope's `warnings` field, and stderr stays empty.
- Post-install output no longer leaves fragments of terminal escape sequences.
- `version-install` now accepts older bottles that it rejected before, for example `oniguruma 6.9.9` and `jq 1.8.1`. Old bottle indexes record only a creation date. Bottles for a newer macOS were often added to an index months after the first upload. The bottle must still have the same digest in GHCR and in homebrew-core history.
